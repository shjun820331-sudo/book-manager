# 서비스 기획서 — [가칭] 북토크 나침반

작성일: 2026-09-18 (초안, 세부 사항은 확정 전)

## 1. 서비스 개요

- **서비스명(가칭)**: 북토크 나침반 — 언제든 원하는 이름으로 변경 가능
- **한 줄 소개**: 책 제목만 입력하면 저자 소개와 줄거리를 알려주고, 독서
  모임의 연령대·목적에 맞는 토론 주제를 AI가 추천해주는 독서모임 준비
  도우미

## 2. 목적 및 배경

- **문제**: 독서모임이나 독서토론 수업을 준비할 때, 책에 대한 배경지식
  (저자 정보, 줄거리)을 따로 검색해서 찾아야 하고, 참여자 특성에 맞는
  좋은 토론 주제를 떠올리기 어렵다.
- **해결**: 책 제목 하나로 저자 소개와 줄거리를 즉시 확인하고, 참여자의
  연령대와 토론 목적을 선택하면 AI가 그에 맞는 토론 주제를 제안해 모임
  준비 시간을 줄여준다.

## 3. 타겟 사용자

- 독서모임 운영자/진행자
- 학교에서 독서토론 수업을 준비하는 교사
- 스터디·북클럽 모임원

## 4. 페이지(섹션) 구성 — 총 4개

| # | 이름 | 내용 |
|---|---|---|
| 1 | 메인(Hero) | 서비스 소개, 이용 흐름 안내, 시작하기 버튼 |
| 2 | 도서 정보 조회 | 책 제목 입력 → 저자 소개 + 줄거리 (**AI 기능 ①**) |
| 3 | 토론 주제 추천 | 책 제목 + 연령대 + 목적 선택 → 이야깃거리/토론주제 추천 (**AI 기능 ②**) |
| 4 | 이용 안내 | 사용법, 주의사항(AI 결과는 참고용이며 정확성에 한계가 있음을 안내) |

**내비게이션 방식(확정)**: 실제 별도 HTML 파일 4개(`index.html`,
`book-info.html`, `discussion.html`, `guide.html`)를 만들고 상단 고정
네비게이션 바(`<a href="...">`)로 이동한다. 도서 정보 조회(②) 결과의
책 제목은 URL 쿼리스트링(`discussion.html?title=...`)으로 토론 주제
추천(③) 페이지에 자동 전달한다.

## 5. AI 기능 설계

### AI 기능 ① 도서 정보 조회

- **입력**: 책 제목 (텍스트, 필수)
- **출력**: 저자 소개(작품 경향, 주요 수상 내역, 작가 히스토리, 대표작) +
  줄거리 요약 (스포일러 최소화)
- **실패 처리**:
  - 빈 입력 → "책 제목을 입력해주세요"
  - API 오류(4xx/5xx) → "정보를 가져오지 못했어요. 잠시 후 다시
    시도해주세요"
  - 지연(응답 10초 이상) → "응답이 지연되고 있어요" 안내 + 재시도 버튼

### AI 기능 ② 토론 주제 추천

- **입력**: 책 제목(②페이지 진입 시 ①에서 조회한 제목이 자동으로 채워짐,
  직접 입력·수정도 가능) + 연령대(초등 / 중·고등학생 / 대학생·성인 /
  시니어 중 선택) + 토론 목적(감상 나누기 / 비판적 사고 훈련 / 글쓰기
  연계 / 교육과정 연계 중 선택)
- **출력**: 이야깃거리 목록 + 토론 주제 목록 (각 5~7개, 항목별 짧은 설명
  포함)
- **실패 처리**:
  - 필수값(책 제목/연령대/목적) 누락 → "필수 항목을 모두 선택해주세요"
  - API 오류 → "추천을 가져오지 못했어요. 다시 시도해주세요"
  - 지연 → 로딩 표시 + 타임아웃 안내

## 6. 핵심 사용자 흐름

```
메인 진입
  → "책 정보 찾기" 클릭
  → 책 제목 입력 → 저자소개 + 줄거리 확인
  → "토론 주제 추천받기" 이동
  → 연령대 / 목적 선택
  → 추천 이야깃거리 · 토론주제 목록 확인
  → (실제 독서모임에서 활용)
```

## 7. 실패 처리 정책 요약 (과제 요구사항 대응)

과제에서 요구하는 최소 1개 이상의 실패 처리 안내를, 아래 3가지 모두
구현할 예정:

- 빈 입력(필수값 누락)
- API 오류(4xx/5xx)
- 지연/타임아웃

## 8. 기술 결정 사항 (확정)

- **AI API**: OpenAI API (Chat Completions, JSON 응답 모드 사용)
- **페이지 구성**: 실제 별도 HTML 파일 4개 (멀티페이지 방식)
- **서비스 이름**: 가칭 "북토크 나침반" 유지 (추후 변경 가능)
